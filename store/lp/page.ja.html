できること

リサイズから撮影・保存まで、ポップアップひとつで完結。

ワンクリックでリサイズ

ウィンドウ全体、またはページの表示領域（ビューポート）を基準に指定サイズへ。

プリセット＋カスタムサイズ

よく使う解像度を内蔵。自分用のサイズも追加・編集・削除できます。

表示範囲もページ全体も撮れる

全体キャプチャは自動でスクロールし、1枚の画像につなぎ合わせます。

内側だけスクロールするページも

Webアプリの管理画面のように、ページの内側だけがスクロールする画面でも、メインのスクロール範囲を自動で見つけて最後まで撮影します。

範囲を選んで撮影

ページ上のスクロール範囲をクリックで選んで、その範囲だけをダウンロード・コピーできます。

保存もコピーもワンクリック

ダウンロードのほか、クリップボードへ PNG でコピーしてそのまま貼り付け。ダウンロードはポップアップがすぐ閉じて、結果はツールバーのアイコンでお知らせします。

「ウィンドウ基準」と「ビューポート基準」

用途に合わせて、どこを指定サイズにするか選べます。

ウィンドウ基準

画面全体の見た目を揃えたいときに

ツールバーも含めたウィンドウ全体を指定サイズにします。ページが表示される部分は、ツールバーの分だけ小さくなります。

ビューポート基準

スクショの画像サイズを揃えたいときに

ページが表示される部分を指定サイズにします。ウィンドウはツールバーの分だけ大きくなります。

ページ全体も、1枚にまとめて

縦に長いページも自動スクロールでまるごとキャプチャ。内側だけがスクロールするページでは、ヘッダーやサイドバーなどの外枠を含めるかも選べます。

インストール

Chrome ウェブストアから追加し、ツールバーにピン留め。

サイズを選ぶ

ポップアップから基準とサイズを選んでリサイズ。

撮影して保存

表示範囲かページ全体を選んで、保存またはコピー。結果はツールバーのアイコンに「OK」と表示されます。

細かいところも便利に

 

  • PNG / WebP / JPEG から保存形式を選べる
  • 拡大表示中のページは 100% に戻してからリサイズ（確認の表示は切り替え可）
  • スクロール範囲の撮影で、外枠を含めるか選べる
  • 撮影の結果をツールバーのアイコンでお知らせ
  • 保存先フォルダ名を指定できる
  • 前回の基準・モードを記憶
  • 環境ごとのズレを補正オフセットで調整
  • ダークモード対応のポップアップ
  • 日本語 / English 切り替え（ブラウザ言語に追従も可）

よくある質問

 

動かないページがあります

chrome:// で始まるページや Chrome ウェブストアなどの特殊なページでは、Chrome の仕様によりリサイズやキャプチャができません。

指定したサイズと数 px ずれます

OS の表示倍率やウィンドウ枠の影響です。設定画面のプリセットごとの補正オフセットで調整できます。

ブラウザのツールバーも写りますか？

いいえ。キャプチャされるのは Web ページの部分のみで、ツールバーや OS のウィンドウ枠は含まれません。

ページを拡大表示していると、指定したサイズになりません

拡大率が 100% 以外のページでは、100% に戻してからリサイズします。戻す前の確認メッセージは設定画面で非表示にできます。

ページ全体を撮っても1画面分しか撮れません

ページの内側だけがスクロールする画面では、メインのスクロール範囲を自動で判定して撮影します。うまく判定できないときは、ポップアップの「ページ全体」の行にある範囲選択ボタン（カーソルのアイコン）を押し、撮りたい範囲をクリックして選んでください。

範囲を選んだあとに「コピー」が出ません

http のページなど、ブラウザがクリップボードへの書き込みを許可していないページではコピーを表示しません。ダウンロードをお使いください。

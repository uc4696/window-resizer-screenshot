## 7. よくある質問

**操作**: Q&A を3つ追加（既存3つの後）。既存3つは変更なし。

- 日
  - Q: ページを拡大表示していると、指定したサイズになりません
    A: 拡大率が 100% 以外のページでは、100% に戻してからリサイズします。戻す前の確認メッセージは設定画面で非表示にできます。
  - Q: ページ全体を撮っても1画面分しか撮れません
    A: ページの内側だけがスクロールする画面では、メインのスクロール範囲を自動で判定して撮影します。うまく判定できないときは、ポップアップの「ページ全体」の行にある範囲選択ボタン（カーソルのアイコン）を押し、撮りたい範囲をクリックして選んでください。
  - Q: 範囲を選んだあとに「コピー」が出ません
    A: http のページなど、ブラウザがクリップボードへの書き込みを許可していないページではコピーを表示しません。ダウンロードをお使いください。
- 英
  - Q: The size is wrong when the page is zoomed
    A: If the page zoom is not 100%, it is reset to 100% before resizing. You can turn off the confirmation message in the settings.
  - Q: Full-page capture only takes one screen
    A: On pages where only an inner area scrolls, the main scrollable area is detected and captured automatically. If that doesn't work, press the area-picking button (the cursor icon) in the "Full page" row of the popup, then click the area you want.
  - Q: "Copy" doesn't appear after picking an area
    A: On pages where the browser doesn't allow writing to the clipboard, such as http pages, Copy is not shown. Please use Download instead.

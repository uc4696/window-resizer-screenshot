What it does

From resizing to capturing and saving, all from one popup.

One-click resizing

Set the whole window, or just the page area (the viewport), to an exact size.

Presets and custom sizes

Common resolutions are built in. Add, edit and delete your own sizes, too.

Visible area or full page

Full-page capture scrolls automatically and stitches everything into one image.

Pages that scroll inside

On pages where only an inner area scrolls, like web app dashboards, the main scrollable area is found automatically and captured to the end.

Pick an area to capture

Click a scrollable area on the page to download or copy just that area.

Save or copy in one click

Download the image, or copy it to the clipboard as PNG and paste it right away. When you download, the popup closes at once and the toolbar icon shows the result.

Window-based vs. viewport-based

Choose which part of the browser gets the exact size.

Window-based

Best for matching the overall look

Resizes the whole window, toolbars included. The page area ends up smaller by the height of the toolbars.

Viewport-based

Best for consistent screenshot sizes

Resizes only the area where the page is shown. The window grows by the height of the toolbars.

FAQ

 

It doesn't work on some pages

Chrome doesn't allow extensions to resize or capture special pages, such as those starting with chrome:// or the Chrome Web Store.

The size is off by a few pixels

This comes from your OS display scaling or window borders. You can correct it with the per-preset offsets in the settings.

Are the browser toolbars captured too?

No. Only the web page itself is captured, without the toolbars or the OS window frame.

The size is wrong when the page is zoomed

If the page zoom is not 100%, it is reset to 100% before resizing. You can turn off the confirmation message in the settings.

Full-page capture only takes one screen

On pages where only an inner area scrolls, the main scrollable area is detected and captured automatically. If that doesn't work, press the area-picking button (the cursor icon) in the "Full page" row of the popup, then click the area you want.

"Copy" doesn't appear after picking an area

On pages where the browser doesn't allow writing to the clipboard, such as http pages, Copy is not shown. Please use Download instead.

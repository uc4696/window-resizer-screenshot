## 3. よくある質問

**操作**: 2 問を差し替え。

### 拡大表示
- 日（問）: ページを拡大表示しているときのサイズは？
- 日（答）: 拡大率はビューポートのサイズに影響しません。拡大したまま指定のサイズになり、撮影した画像も同じサイズになります。ページ全体の画像の高さは、拡大後のページの高さです。
- 英（問）: What size do I get when the page is zoomed?
- 英（答）: Zoom does not affect the viewport size. The page stays zoomed at the size you set, and the captured image has the same size. A full-page image is as tall as the zoomed page.

### 数 px のズレ
- 日（問）: 指定したサイズと数 px ずれませんか？
- 日（答）: ビューポート基準では、OS の表示倍率が 125% などでも、指定したサイズと画像のサイズが同じになります。ウィンドウ基準では OS の表示倍率やウィンドウ枠の影響でずれることがあり、設定画面のプリセットごとの補正オフセットで調整できます。
- 英（問）: Can the size be off by a few pixels?
- 英（答）: In viewport-based mode, the size you set is the size of the image, even at an OS display scale such as 125%. In window-based mode, OS display scaling and window borders can cause small differences, which you can correct with the per-preset offsets in the settings.

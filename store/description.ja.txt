「Window & Viewport Resizer」は、指定したサイズでスクリーンショットを撮影するための拡張機能です。
ワンクリックで画面（ウィンドウ・ビューポート）を目的の解像度に切り替えることができ、表示領域やページ全体のキャプチャを保存・コピーできます。ブログ記事やマニュアル・手順書などの作成に活用できます。

【主な機能】
◆ 画面リサイズ（ウィンドウ / ビューポート対応）
- 16:9（HD / FHD / WQHD / 4K）や 4:3（VGA / SVGA / XGA / UXGA）などの解像度プリセットを標準搭載。
- ウィンドウ基準・ビューポート基準に合わせた補正オフセット（マージン）値を、プリセットごとに設定可能。
- 最後に選んだサイズ基準（ウィンドウ / ビューポート）を記憶し、次回も同じ基準で起動。
- ページが拡大縮小（100% 以外）されているときは、意図したサイズになるよう拡大率を 100% に戻してからリサイズ（確認メッセージの表示は設定で切り替え可能）。

◆ カスタムサイズの登録
- 指定の解像度サイズ（例: 1280×720、1024×768など）をあらかじめ登録可能。追加・編集・削除に対応。
- 登録したサイズはポップアップから呼び出せます。

◆ スクリーンショット撮影
- 「表示部分（Visible Area）」および「ページ全体（Full Page）」の撮影に対応。
- ページ全体撮影は自動スクロールを行って1枚の画像として保存。
- ページ自体はスクロールせず内側の領域だけがスクロールするページ（Webアプリの管理画面など）でも、主要なスクロール範囲を自動で判定して最後まで撮影。
- ページ上のスクロール範囲をクリックで選んで、その範囲だけをダウンロード / コピーすることも可能。
- スクロール範囲の撮影時に、ヘッダーやサイドバーなどの外枠を含めるかを設定で選択可能。
- 保存形式は PNG（既定）/ WebP / JPEG から選択可能。
- 撮影した画像をクリップボードへコピー可能（PNG形式）。
- 保存先フォルダ名の指定が可能。
- わかりやすいアイコンボタンで、ダウンロード/コピーをワンタップで実行。
- ダウンロードを押すとポップアップはすぐ閉じ、撮影の結果はツールバーアイコンのバッジ（撮影中「...」/ 成功「OK」/ 失敗「!」）でお知らせ。

◆ オプション設定
- ダークモード対応のポップアップUI。
- 設定データやカスタムサイズを初期状態に戻すリセット機能。
- 日本語・英語の表示言語切り替え対応（ブラウザ言語への自動追従も可能）。

◆ プライバシーと権限
- 必要最小限の権限（activeTab / scripting / storage / downloads）のみで動作します。
- 撮影した画像や設定が外部サーバーへ送信されることはありません。

【ご利用上の注意】
- スクリーンショットの対象は、タブ内のWebページ表示領域です。ブラウザのツールバーやOSのタイトルバーを含むウィンドウ全体は撮影できません。
- Chromeのセキュリティ上の制限により、chrome:// ページやChromeウェブストアなどの特殊ページでは、ビューポート基準のリサイズやスクリーンショットが利用できない場合があります。
- OSの表示スケーリングやウィンドウ枠の仕様により、実測サイズが指定サイズと数px異なる場合があります（カスタムサイズの補正オフセットで調整できます）。

※本拡張機能は現在ベータ版としての提供となります。

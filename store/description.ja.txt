「Window & Viewport Resizer」は、指定したサイズでスクリーンショットを撮影するための拡張機能です。
ワンクリックで画面（ウィンドウ・ビューポート）を目的の解像度に切り替えることができ、表示領域やページ全体のキャプチャを保存・コピーできます。ブログ記事やマニュアル・手順書などの作成に活用できます。

【主な機能】
◆ 画面リサイズ（ウィンドウ / ビューポート対応）
- 16:9（HD / WXGA / HD+ / FHD）や 4:3（VGA / SVGA / XGA / UXGA）などの解像度プリセットを標準搭載。
- ウィンドウ基準・ビューポート基準に合わせた補正オフセット（マージン）値を、プリセットごとに設定可能。
- 最後に選んだサイズ基準（ウィンドウ / ビューポート）を記憶し、次回も同じ基準で起動。
- ビューポート基準で指定したサイズと、撮影した画像のサイズが同じに。ページの拡大率やOSの表示スケールが変わっても、同じサイズの画像を撮れます。
- ページを拡大表示したままでも、拡大率を変えずに指定のサイズへリサイズ。
- ウィンドウが画面からはみ出さないよう、位置を自動で調整（設定でオフにできます）。

◆ カスタムサイズの登録
- 指定の解像度サイズ（例: 1280×720、1024×768など）をあらかじめ登録可能。追加・編集・削除に対応。
- 登録したサイズはポップアップから呼び出せます。

◆ スクリーンショット撮影
- 「表示部分（Visible Area）」および「ページ全体（Full Page）」の撮影に対応。
- ページ全体撮影は自動スクロールを行って1枚の画像として保存。
- ページ自体はスクロールせず内側の領域だけがスクロールするページ（Webアプリの管理画面など）でも、主要なスクロール範囲を自動で判定して最後まで撮影。
- ページ上のスクロール範囲をクリックで選んで、その範囲だけをダウンロード / コピーすることも可能。
- スクロール範囲の撮影時に、ヘッダーやサイドバーなどの外枠を含めるかを設定で選択可能。
- 保存形式は PNG（既定）/ WebP / JPEG から選択可能。
- 撮影した画像をクリップボードへコピー可能（PNG形式）。
- 保存先フォルダ名の指定が可能。
- わかりやすいアイコンボタンで、ダウンロード/コピーをワンタップで実行。
- ダウンロードを押すとポップアップはすぐ閉じ、撮影の結果はツールバーアイコンのバッジ（撮影中「...」/ 成功「OK」/ 失敗「!」）でお知らせ。
- 3・5・10秒のタイマー撮影で、ホバーで開くメニューなども撮影可能。

◆ キーボードショートカット
- プリセットやカスタムサイズ（5枠）へのリサイズと、各種の撮影に好きなキーを割り当て可能（既定では何も割り当てません）。

◆ オプション設定
- ライト / ダーク / 自動から選べるテーマ。
- 設定は変更した時点で自動で保存。
- 設定データやカスタムサイズを初期状態に戻すリセット機能。
- 日本語・英語の表示言語切り替え対応（ブラウザ言語への自動追従も可能）。

◆ プライバシーと権限
- 必要最小限の権限（activeTab / scripting / storage / downloads）のみで動作します。
- 撮影した画像や設定が外部サーバーへ送信されることはありません。

【ご利用上の注意】
- スクリーンショットの対象は、タブ内のWebページ表示領域です。ブラウザのツールバーやOSのタイトルバーを含むウィンドウ全体は撮影できません。
- Chromeのセキュリティ上の制限により、chrome:// ページやChromeウェブストアなどの特殊ページでは、スクリーンショットの一部の機能が利用できない場合があります。
- ディスプレイより大きいサイズは選べません。ビューポート基準では、ブラウザの枠を含めてディスプレイに収まるサイズを選べます。
- ウィンドウ基準では、OSの表示スケーリングやウィンドウ枠の仕様により、実測サイズが指定サイズと数px異なる場合があります（カスタムサイズの補正オフセットで調整できます）。
- 高精細な画面でも、画像は指定のサイズになるよう縮小して保存します。

【変更履歴】
- 1.0.0: 正式版になりました。ビューポート基準で指定したサイズと、撮影した画像のサイズが同じになるようにしました。拡大率を変えずにリサイズするようにしました。プリセットの16:9をHD / WXGA / HD+ / FHDにしました（WQHDと4Kを削除）。キーボードショートカット、タイマー撮影、はみ出し防止、テーマの設定を追加し、SNSの共有先を増やしました。ディスプレイに収まらないサイズは選べないようにしました。ポップアップと設定画面を使いやすく整えました。拡大中のページ全体の撮影で、つなぎ目に線が出る不具合を直しました。
- 0.4.0: ページの拡大率が100%以外のときのリサイズに対応しました。ツールバーのアイコンを見やすくしました。
- 0.3.0: 内側だけスクロールするページの撮影と、範囲を選んでの撮影を追加しました。
- 0.2.1: アイコンの表示を直し、最後に選んだサイズ基準を記憶するようにしました。
- 0.2.0: 保存形式（PNG / WebP / JPEG）とクリップボードへのコピーを追加しました。
- 0.1.1: 必要な権限を減らしました。
- 初版（ベータ版）を公開しました。
